# 🚀 Selected Builds

## 🌾 KrishiDrishti

### AI-Powered Smart Farming Assistant

<a href="https://github.com/HQHimanshu/KrishiDrishti">
<img src="https://img.shields.io/badge/VIEW_PROJECT-2ea44f?style=for-the-badge&logo=github&logoColor=white"/>
</a>

**Smart India Hackathon PS-301 · IoT + AI + Agriculture**

KrishiDrishti is an end-to-end smart agriculture system designed for Indian farming environments.

The system combines **real-time sensor data, local AI, RAG, multilingual assistance and offline-first software** into a single platform.

### What makes it interesting

- 📡 Real-time data from Arduino-connected sensors
- 🤖 RAG-based agricultural assistance using Qwen 2.5
- 🧠 Local AI inference through Ollama
- 🌐 ChromaDB + sentence-transformers for retrieval
- 🌍 English, Hindi and Marathi support
- 🔊 Voice-based alerts
- 📱 Offline-first PWA architecture
- 💧 Water, fertilizer and resource tracking
- 📲 WhatsApp / SMS / email notifications

### Architecture

```text
Sensors
  │
  ▼
Arduino
  │
  ▼
FastAPI Backend
  │
  ├──────────────► Sensor & Resource Data
  │
  ├──────────────► ChromaDB RAG
  │                       │
  │                       ▼
  │                  Qwen 2.5
  │                  Local Inference
  │
  └──────────────► Notification Layer
                          │
                          ├── WhatsApp
                          ├── SMS
                          ├── Email
                          └── Voice

                    ▼

              React + Vite PWA
```

**Stack:** `Python` `FastAPI` `React` `Vite` `TailwindCSS` `Ollama` `Qwen` `ChromaDB` `Arduino` `SQLite` `PWA`

> **Engineering lesson:** technology becomes useful when it is designed around the constraints of the people using it.
